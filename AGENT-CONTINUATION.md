# AGENT-CONTINUATION.md — с чего начать работу

Памятка для агента, который продолжает работу над проектом. Если предыдущий чат потерялся,
читайте этот файл, затем `AGENTS.md` (устройство проекта) и `README-BUILD.md` (сборка приложения).

## 1. Что это за проект

Electron-приложение «ADB Wi-Fi Коннектор» для Windows x64 — беспроводная отладка Android
по Wi-Fi (adb + scrcpy), русский интерфейс. Версия продукта 3.0. Установщик — собственный,
на C#/WinForms, один EXE с установкой и портативным режимом.

## 2. Карта репозитория

```
main.js                 главный процесс Electron
adb.js                  обёртка над adb.exe
mdns.js                 обнаружение mDNS
agent-mcp.js            MCP-сервер (порт 3939)
renderer/               интерфейс: index.html, styles.css, app.js, lib/
camera/                 камера и микрофон: Python-серверы, C++ src, Android-приложение, драйверы
installer/src/          установщик и деинсталлятор (C#)
release/                готовый установщик (не хранится в git, см. Releases)
docs/screenshots/       скриншоты и overview.gif для README
shellext/               готовая оболочка Explorer (DLL + лицензии)
tools/                  launcher.c, launcher.rc, patch-icon.js
```

Портативная сборка (`APP/`) и лаунчер в репозитории не лежат: они собираются отдельно и
упаковываются установщиком. Установщик пакует `APP/`, `ADB-WiFi-Connector-RU.exe`, `README-RU.md`
и `Uninstall.exe` из родительской папки пакета.

## 3. Как править приложение

- Версия берётся из `package.json` через `app.getVersion()`.
- Быстрая правка: изменить файлы в исходнике, скопировать их в `APP/resources/app/`
  (та же структура) и в установленную копию `C:\Program Files\ADB Wi-Fi Connector\APP\resources\app\`,
  затем перезапустить приложение — Electron читает JS только при старте.
- Полная пересборка приложения — по `README-BUILD.md`; на Windows проще собрать установщик
  вокруг уже готового `APP`.
- Пользовательские данные (`Сохранения/`: `config.json`, `history.json`, `favorites.json`, `saved.json`,
  `Мои команды.json`, `unlock.json`) в git не попадают никогда.

## 4. Сборка установщика

Полный цикл — раздел 6 в `AGENTS.md`: `Uninstall.exe` → `Setup.exe`/`SetupTest.exe` → `payload.zip`
→ дописать payload и хвост `ADBWIFISETUP0001` к финальному EXE → превью → проверка `/extract`.

Нормальные числа для версии 3.0:

- payload: 192 записи, 133 970 040 байт;
- финальный EXE: 134 210 192 байт (SHA-256 записывать и передавать пользователю);
- распаковка `/extract`: 176 файлов, ~310 МБ; в `package.json` версия 3.0, нет `Сохранения`.

Нужны только `csc.exe` из .NET Framework и `tar.exe` из System32. Inno Setup, NSIS и 7-Zip
не используются — не устанавливать.

## 5. Как обновлять GitHub

Репозиторий: `https://github.com/flash72i/ADB_WiFi_Connector_v3.0`, ветка `main`, тег `v3.0`.

1. Свежий клон во временную папку.
2. Скопировать изменённые файлы из рабочей папки (не забыть `renderer/*`, `camera/*`,
   `docs/screenshots/*`, `README.md`, `AGENTS.md`).
3. Проверить утечки (раздел 6).
4. Коммит по-русски, коротко, про суть изменения. Changelog-разделов не писать.
5. Push в `main`.
6. Тег `v3.0` перенести force на новый коммит.
7. Релиз `v3.0`: загрузить EXE под временным именем, сверить размер и digest, удалить старый asset,
   переименовать новый. Описание релиза оставлять пустым.
8. Проверить: ссылка latest отдаёт 200 и точный размер, raw-файлы на теге содержат правки.

Если git зависает на запросе пароля (Git Credential Manager), отключить helper:

```powershell
$env:GIT_TERMINAL_PROMPT = "0"
git -c credential.helper= -c http.version=HTTP/1.1 clone <url> <dir>
```

Токен передавать только через `-c http.extraHeader="Authorization: Basic <base64>"`,
не печатать и не сохранять в файлы; после работы просить пользователя его отозвать.

## 6. Приватность

Репозиторий публичный. Нельзя коммитить: домашние пути `C:\Users\<имя>`, имя владельца,
реальные IP и serial устройств, модели телефона и телевизора, e-mail, токены, `app.log`,
`Сохранения/`, `config.json`, скриншоты с путями пользователя. Примеры IP — только документационные
вида `192.0.2.42:5555`.

Подпись «Автор: Рэйф_72» на скриншотах оставлена осознанно — это не утечка.

Проверка перед коммитом — поиск по
`C:\\Users|192\.168\.|@gmail|@yandex|ghp_|api[_-]?key|secret`.

## 7. Грабли (проверено на практике)

- `.gitignore` со строкой `APP/` матчит `camera/android-cam/app/` и молча выбрасывает исходник
  Android-приложения. Писать `/APP/`; так же `/release/`.
- `__pycache__/`, `*.pyc` — исключены, не коммитить.
- Телевизор: `adb pull /data/app/.../base.apk` падает с «remote object does not exist». Работает
  обход: `shell cp` в `/sdcard/Download`, затем `pull`, затем `rm`. В `main.js` это `pullApkFile()`,
  используется для сохранения APK, бэкапа и иконок.
- На телевизоре нет `unzip` — быстрый разбор APK там не работает, нужен запасной путь.
- Установленная копия обновляется только копированием файлов; без перезапуска правки не видны.
