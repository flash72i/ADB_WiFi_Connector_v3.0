Способы подключения

🌐 По IP-адресу

Если телефон уже сопряжён (или открыт порт 5555): введите адрес с экрана «Беспроводная отладка» — строка «IP-адрес и порт».

🔒 Беспроводное сопряжение (Android 11+, первый раз)

На телефоне: «Параметры разработчика» → «Беспроводная отладка» → «Сопряжение устройства по коду». Введите показанные адрес и код — или нажмите «QR-код на телефон»: код появится сразу под кнопкой, наведите камеру телефона.

Настройки


      

        
Поведение при запуске

        
        
        
        
        
        
        
Без вашего явного выбора приложение никогда не подключается к устройствам самостоятельно (R3).

      


      

        
Ассоциации файлов

        
Открывать APK/XAPK/APKS/APKM/OBB/AAB двойным кликом в «ADB Wi-Fi Коннектор» — файл появится в очереди установки с иконкой и именем приложения. Работает на уровне системы (реестр HKCU).

        
        

        

          
      


      

        
Иконки приложений в Проводнике

        
Показывать настоящую иконку приложения для файлов .apk, .aab, .xapk, .apkm, .apks, .apkv, .obb — вместо общего значка программы. Установка один раз требует подтверждения администратора Windows (UAC) и перезапуска Проводника.

        
        

        

          
        

        
Компонент: apkshellext (MIT), libwebp 1.5.0 (BSD). Только 64-битный Проводник. Удаление вернёт общий значок.

Как подключить

    
    
      
  1. На телефоне включите «Параметры разработчика» → «Беспроводная отладка».
    2. 
      
  2. Первый раз: нажмите «QR-код на телефон» — и отсканируйте код камерой телефона
      (на телефоне: «Беспроводная отладка» → «Подключить устройство по QR-коду»); всё произойдёт автоматически.
    3. 
      
  3. Либо на экране «Сопряжение устройства по коду» введите адрес и код в карточке «Беспроводное сопряжение».
    4. 
      
  4. В следующие разы просто подключайтесь по IP (или из истории/избранного) — сопряжение уже выполнено.
    5. 
      
  5. Телефон и компьютер должны быть в одной сети Wi-Fi; сеть Windows — «Частная».

Пароли привязаны к аппаратному серийнику телефона и хранятся зашифрованными.

О программе

    
ADB Wi-Fi Коннектор (RU).

    Независимая русская сборка с открытым интерфейсом: без пробного периода, рекламы и встроенных покупок — все функции доступны сразу.

    В комплекте поставляется adb (Android SDK Platform-Tools) компании Google.
