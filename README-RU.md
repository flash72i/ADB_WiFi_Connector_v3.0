# ADB Wi-Fi Коннектор RU — 3.0

Программа для Windows, которая подключается к Android-телефону по Wi-Fi и позволяет
управлять им с компьютера: работать с файлами и приложениями, смотреть экран,
выполнять команды adb. Root не нужен — используется официальный adb.

## Что умеет

- Подключение по Wi-Fi: QR-код, IP:порт, mDNS; история и избранное устройств.
- Файлы телефона: просмотр, скачивание и загрузка, переименование, удаление,
  архивы ZIP, просмотр DOCX и контактов VCF, работа с USB/OTG-флешками.
- Приложения: список, установка APK, запуск и остановка, очистка данных и кэша.
- Экран и управление: scrcpy, скриншоты, запись видео, буфер обмена.
- Терминал adb и MCP-сервер для ИИ-агентов.
- Иконки APK в Проводнике Windows.

## Как подключить

1. На телефоне: «Для разработчиков» → «Беспроводная отладка».
2. Телефон и компьютер — в одной сети Wi-Fi; сеть Windows должна быть «Частной».
3. В программе: «QR-код на телефон» или ввести IP:порт с экрана отладки.
   При первом подключении телефон попросит сопряжение.

## Состав папки

- `ADB-WiFi-Connector-RU.exe` — лаунчер.
- `APP\` — Electron и приложение; `APP\resources\adb` — adb, `APP\resources\scrcpy` — scrcpy.
- `Сохранения\` — настройки, история, избранное, скриншоты и видео.
- `app.log` — журнал ошибок и диагностики.

## Папка «Сохранения»

Папка всегда создаётся при первом запуске рядом с лаунчером:

- портативная версия — в папке, куда распакован архив;
- установленная версия — `C:\Program Files\ADB Wi-Fi Connector\Сохранения`.

Внутри: `config.json` (настройки), `history.json` (до 50 устройств),
`favorites.json`, `saved.json`, `Мои команды.json`, `unlock.json` (PIN/пароль
в зашифрованном виде), `Захваты\` (скриншоты/видео), `Агент\` (снимки MCP-агента),
`labels-*.json` (кэш названий приложений).

Удаление папки сбрасывает настройки и историю; при следующем запуске она создаётся
заново. Без неё программа работает, но не сохраняет настройки между запусками.
